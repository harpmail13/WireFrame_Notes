# Welcome to the WireFrame_Notes Repository
This is **WireFrame_Notes**, an open-source (Polyform Noncommercial 1.0.0) project providing a power-user-focused note-taking web app.

---
**Key Features:**
- Markdown-based standard notes 
- Optimized mind maps
- Integrated math solving
- OpenRouter-connected AI notes
- GitHub-based cloud sync (Future)
